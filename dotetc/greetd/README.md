# greetd + noctalia-greeter → niri (Asahi / ALARM)

How the graphical login on this machine is set up, so it can be reproduced on
the work laptop and home desktop. Set up **2026-09-07**, replacing SDDM.

## What we ended up with

- **greetd** (`0.10.3`) is the login daemon and the system `display-manager`.
- **noctalia-greeter** (`1.3.1`) is the greeter — a minimal greetd greeter that
  ships its own bundled wlroots compositor (`noctalia-greeter-compositor`) and
  matches the Noctalia shell look. It gives a user/password prompt plus a
  **session picker (F3)** and **colour-scheme picker (F7)**.
- The session it launches is **niri** (`26.04`) — now the daily driver.
- **Hyprland** and **Umbriel** remain installed and are still offered in the
  greeter's session list as fallbacks (Hyprland = safety net, Umbriel = watching
  whether it overtakes niri). Do not remove them.

Sessions the greeter currently lists (from `noctalia-greeter sessions`, sourced
from `/usr/share/wayland-sessions/*.desktop`):
Weston, Hyprland (uwsm-managed), Hyprland, labwc, Umbriel, Niri.

## The pieces in this repo

| Repo path | Installs to | What it is |
|-----------|-------------|------------|
| `dotetc/greetd/config.toml`     | `/etc/greetd/config.toml`      | greetd config — points `[default_session]` at the noctalia greeter |
| `dotetc/greetd/config.toml.bak` | (reference only)               | the stock AUR default (agreety) we replaced, kept for diffing |
| `dotconfig/niri/config.kdl`     | `~/.config/niri/config.kdl`    | the niri session config |
| `dotconfig/niri/noctalia.kdl`   | `~/.config/niri/noctalia.kdl`  | palette include, **regenerated by noctalia** — placeholder in git |

> `dotetc/` is a new mirror of `/etc/` in this repo (analogous to `dotstate/`
> mirroring `~/.local/state/`). Files are copies, not symlinks, per repo
> convention. Restoring `/etc` files needs `sudo`.

## The whole `config.toml` change

The only edit over the AUR default (`config.toml.bak`) is `[default_session]`:

```toml
[default_session]
command = "/usr/bin/noctalia-greeter-session"
user = "greeter"
```

`command` **must** be the wrapper `noctalia-greeter-session` (it starts the
bundled compositor and sets up `WAYLAND_DISPLAY`) — verify the path with
`which noctalia-greeter-session` (packaged install = `/usr/bin`, not
`/usr/local/bin`). `user = "greeter"` is the unprivileged greetd account.

No default session is pinned, so the greeter opens on the **last-used** session.
To force one, append `-- --session niri` to `command`.

## Reproducing on another ALARM machine

```sh
# 1. Packages (AUR for the greeter)
sudo pacman -S greetd niri
paru -S noctalia-greeter          # pulls wlroots0.20 etc.

# 2. Greeter system state (creates /var/lib/noctalia-greeter, PAM, greeter user)
#    The package ships these; run if the state dir is missing:
sudo /usr/share/noctalia-greeter/setup_greeter_system.sh
#    (setup_greetd_pam.sh handles the PAM stack if needed)

# 3. greetd config — copy this repo's file into place
sudo install -Dm644 dotetc/greetd/config.toml /etc/greetd/config.toml
#    Sanity-check the exact block the package recommends:
noctalia-greeter-print-greetd-config

# 4. niri session config
install -Dm644 dotconfig/niri/config.kdl   ~/.config/niri/config.kdl
install -Dm644 dotconfig/niri/noctalia.kdl ~/.config/niri/noctalia.kdl

# 5. Switch the display manager: greetd on, SDDM off
sudo systemctl disable --now sddm     # if SDDM was the old DM
sudo systemctl enable  --now greetd

# 6. (optional) match the greeter to the Noctalia shell palette:
#    Noctalia Shell → Settings → Security → Noctalia Greeter → Sync Now
#    (stages sync.toml + wallpaper into /var/lib/noctalia-greeter/)
```

Verify: `systemctl is-active greetd` = active, and
`readlink -f /etc/systemd/system/display-manager.service` → `greetd.service`.

## niri config notes

- `output "eDP-1" { mode "3024x1890@120"; scale 1.0 }` — **native scale** for
  maximum screen estate (the thing liked about Umbriel). Adjust per machine —
  the work laptop / desktop have different panels.
- `spawn-at-startup "noctalia" "-d"` runs the Noctalia shell (bar, launcher,
  notifications, wallpaper, control centre) — same as under Hyprland/Umbriel.
- Binds mirror the Hyprland muscle memory: `Mod+Space` → noctalia launcher,
  `Mod+L` → noctalia lock, `Mod+Return` → kitty, plus niri's scrollable-column
  navigation. `Mod+Shift+Slash` shows niri's hotkey overlay.
- `include "noctalia.kdl"` is regenerated by noctalia when a palette is applied,
  so the committed copy is just a placeholder.

## Appearance / state that is NOT in git

`/var/lib/noctalia-greeter/` (root-owned) holds the greeter's live state:
`greeter.toml` (declarative: `[output]`, `[cursor]`, `[keyboard]`, `[idle]`,
default session) and `sync.toml` + wallpaper images pushed from the shell's
**Sync Now**. Reconfigure via `greeter.toml` there (see the package README at
`/usr/share/doc/noctalia-greeter/README.md` and
<https://docs.noctalia.dev/v5/greeter/>). Restart with
`sudo systemctl restart greetd` after changes.

## Troubleshooting quick refs

- Blank/black screen → `journalctl -u greetd` (syslog id `noctalia-greeter`);
  confirm `/var/lib/noctalia-greeter` exists.
- `Failed to spawn client` / `WAYLAND_DISPLAY is not set` → `command` must be the
  full path to `noctalia-greeter-session`.
- Wrong session on boot → last-used wins unless `[session].default` is set in
  `greeter.toml`; `noctalia-greeter sessions` prints exact names.
- `Ctrl+Alt+F1..F12` switches VTs from the greeter if it wedges.
